## Convenciones de código
- CSS con metodología BEM (`bloque__elemento--modificador`).
- Enfoque mobile first: estilos base para móvil y `@media (min-width: ...)` para pantallas más grandes.
- Usar variables CSS (`--nombre`) para colores, tipografías y espaciados.

## Cómo trabajar conmigo
- Explícame cada cambio que hagas y por qué, en español y de forma sencilla.
- Explícame los conceptos nuevos que aparezcan al trabajar.
- Mientras arreglamos o añadimos código, repasa brevemente conceptos e ideas que ya vimos antes.
- Cuando haya errores simples, dime dónde están y deja que yo intente corregirlos primero.
